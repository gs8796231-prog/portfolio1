Gaurav Sharma - Portfolio Website

HOW TO OPEN
Double-click index.html. It opens in your browser (internet is needed only for the Google Fonts; the site still works without it).

HOW TO UPDATE
- Photo: replace images/profile.jpg (a square image works best).
- Text, projects, skills: edit index.html (comments show where).
- Colors and design: edit css/style.css (colors are at the top).
- Certificate image: see the comment in the Certifications section of index.html.
- Project, LinkedIn and GitHub links: replace the placeholders in index.html when you have real links.

HOW TO PUT IT ONLINE (free)
Upload this whole folder to GitHub Pages, Netlify or Vercel.
